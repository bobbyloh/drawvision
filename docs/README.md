# DrawVision Documentation

DrawVision is being rebuilt as a sketch-to-insight platform with command-first CAD control, vision-assisted interpretation, analytics, and presentation-ready outputs.

## Documentation Set

- `installation-guide.md`: how to run DrawVision locally and from GitHub Pages.
- `user-manual.md`: basic UI, tools, command prompt, and modeling workflows.
- `command-reference.md`: supported command syntax and aliases.
- `developer-guide.md`: code structure, modules, and extension direction.
- `testing-plan.md`: unit, integration, and user acceptance testing plan.
- `support.md`: support workflow and issue reporting format.
- `legacy-capability-map.md`: remembered DrawVision/HOK capability map.
- `product-definition.md`: product positioning for drawVision as a sketch-to-insight platform.
- `sketchup-adoption-map.md`: SketchUp-style UI principles adopted into DrawVision's command workflow.
- `sketchup-web-adoption-map.md`: browser workspace, local save/open/download, and web lifecycle mapping.
- `sketchup-web-feature-map.md`: web settings, search, panels, visualization, AI, geolocation, and browser limits.
