# Installation Guide

## GitHub Pages

1. Make the repository public or enable Pages for the repository.
2. Open GitHub repository settings.
3. Go to Pages.
4. Set source to `main` branch and `/ root`.
5. Open the published URL.

## Local Browser

From the project directory:

```bash
python3 -m http.server 8099
```

Open:

```text
http://127.0.0.1:8099
```

## Development Requirements

- Modern browser
- Node.js for tests
- Git for version control

No build step is required for the current prototype.
