# drawVision Product Definition

drawVision by HOK, Inc. Advanced Technology Group is being reconstructed as a sketch-to-insight platform for early-stage architecture, interiors, planning, and engineering workflows.

The product direction is not only CAD drafting. It is a bridge between early design intent and coordinated, structured design information.

## Core Positioning

drawVision helps multidisciplinary teams transform sketches, markups, diagrams, and command-driven geometry into shareable visuals, measurable data, and early design insight.

## Key Capabilities

- Sketch-first workflow: natural pen, touch, mouse, and command-prompt input.
- Smart cleanup: strokes and rough shapes should become cleaner architectural geometry.
- Vision-assisted interpretation: common spatial elements should be recognized and converted into editable elements.
- Rapid visualization: diagrams, massing studies, heat maps, simple 3D, and presentation views.
- Collaboration: comments, sessions, review history, and version checkpoints.
- Interoperability: native DrawVision JSON first, then SVG, DXF, STL, OBJ, BIM/CAD bridges.
- Analytics: area takeoffs, adjacency checks, program fit, utilization, and summary tables.
- Presentation output: layouts, title blocks, client-review templates, and sign-off packages.

## Prototype Scope

The current browser prototype implements the command and UI foundation:

- Command prompt as a primary interface.
- Grid, snapping, axis constraints, line/poly/circle/text input.
- Basic views, zoom, pan, axon, measurement box.
- Entity/layer/scene/settings/search panels.
- Local model save/open/export.
- SketchUp-style browser workflow where useful.

## Next Product Milestones

1. Sketch layer: freehand stroke capture, cleanup, and layer control.
2. Interpretation layer: convert rough sketch strokes to lines, polygons, rooms, doors, windows, symbols.
3. Insight layer: areas, adjacency, room schedule, program fit, utilization summaries.
4. Visualization layer: massing, heat maps, diagram styles, presentation layouts.
5. Collaboration layer: comments, saved versions, review states.
6. Interoperability layer: DXF/SVG/STL/OBJ, then BIM-oriented exchange.
7. AI layer: prompt-to-command-chain and sketch-to-structured-model assistant.
